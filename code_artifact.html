一、增长量 / 减少量百化分核心公式

高频必考

已知现期量 A 和增长率 r，当把 |r| 近似转化为特殊分数 1/n 时：

同比增长（r > 0，r ≈ +1/n）
增长量 ≈ 现期量 ÷ (n + 1)
例：现期 26.5，增长 24.9% ≈ 1/4 → 增长量 ≈ 26.5 ÷ 5 = 5.3
同比下降（r < 0，r ≈ -1/n）
减少量 ≈ 现期量 ÷ (n - 1)
例：现期 420，下降 12.5% = -1/8 → 减少量 ≈ 420 ÷ 7 = 60

二、遇到“非标准百分数”的三大考场变形技巧

1. 互换法（乘积为 100 规律）

因为百分号前面的数字 × n = 100，所以两者可以直接互换位置。例如背熟了 1/15 ≈ 6.7%，考场见到 15.1% 立刻反应为 1/6.7；同理 1/13 ≈ 7.7% ⇔ 13% ≈ 1/7.7，1/17 ≈ 5.9% ⇔ 17% ≈ 1/5.9，1/19 ≈ 5.3% ⇔ 19% ≈ 1/5.3。

真题示例：上海口岸进出口总额 79211.4 亿元，同比增长 15.1% ≈ 1/6.7 → 增长量 ≈ 79211.4 ÷ 7.7，首位商 1，即 1 万亿元以上。
2. 放缩倍数法（小数点移位）

将基础表中的特殊值同时放大或缩小 10 倍、2 倍。例如 33.3% = 1/3 ⇒ 3.33% = 1/30；16.7% = 1/6 ⇒ 1.67% = 1/60；25% = 1/4 ⇒ 2.5% = 1/40。

真题示例：棉花产量 549 万吨，增产 3.5% ≈ 3.33% = 1/30 → 增长量 ≈ 549 ÷ 31 ≈ 17.7，因 3.5% 略大于 3.33%，选略大于 18 的 19 万吨。
3. 取中间值法（卡位法）

当百分数恰好落在两个常用分数中间时，取分母的中间小数。例如 23.3% 介于 25%(1/4) 和 20%(1/5) 之间，可近似取 1/4.3；22.2% 取 1/4.5（即 2/9）；41.5% 介于 50%(1/2) 与 33.3%(1/3) 之间，常记为 1/2.4。

真题示例：水运货物周转量 887.87 亿吨公里，增长率 23.3% ≈ 1/4.3 → 增长量 ≈ 887.87 ÷ 5.3 ≈ 167.5（对应选项 167.8）。
4. 多位数乘法化除法

遇到形如 727 × 167 的多位数乘法，把 167 视作 16.7% × 1000 ≈ (1/6) × 1000，直接口算 727 ÷ 6 × 1000 ≈ 121167，大幅减少列竖式时间。

三、高频易混项速记口诀

1/9 与 1/11 互记： 1/9 ≈ 11.1%，1/11 ≈ 9.1%（9 和 11 互换）。
1/7 与 1/14 折半： 1/7 ≈ 14.3%（七一四），1/14 ≈ 7.1%（正好一半）。
1/8 与 1/16 折半： 1/8 = 12.5%，1/16 = 6.25%（精确无误差）。
1/17, 1/18, 1/19（5.9 / 5.6 / 5.3）： 记住“九六三”等差递减 0.3%！
1/6, 1/12, 1/15： 1/6 ≈ 16.7%，1/12 ≈ 8.3%（折半），1/15 ≈ 6.7%（67 呼应）。

四、考公数推必背：一数多幂（高频敏感数）与幂次修正

一数多幂必背： 64 = 8² = 4³ = 2⁶；81 = 9² = 3⁴；256 = 16² = 4⁴ = 2⁸；625 = 25² = 5⁴；729 = 27² = 9³ = 3⁶；4096 = 64² = 16³ = 8⁴ = 2¹²。
